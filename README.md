# 🚗 ระบบจองที่จอดรถสำหรับนักศึกษา (University Car Park)

ระบบบริหารจัดการช่องจอดรถแบบ Real-time รองรับทั้งนักศึกษาและเจ้าหน้าที่[cite: 30]

---

## ✨ คุณสมบัติเด่น (Features)

**นักศึกษา / ผู้ใช้ทั่วไป:**
* สมัครและเข้าสู่ระบบด้วยอีเมลมหาวิทยาลัย (`.ac.th`)[cite: 28, 30]
* เลือกจองช่องจอดรถ (นับถอยหลัง 30 นาที)[cite: 28, 30]
* กด Check-in เมื่อเข้าจอด และ Check-out เมื่อนำรถออก[cite: 30]
* จำกัดสิทธิ์การใช้งาน 1 สิทธิ์ / 1 บัญชี[cite: 28]

**เจ้าหน้าที่ (Staff Dashboard):**
* ดูผังจอดรถแบบ Real-time (เขียว = ว่าง, ส้ม = จองแล้ว, แดง = มีรถจอด)[cite: 30]
* ปลดล็อกช่องจอดฉุกเฉิน และเซ็ตว่างทั้งหมดได้[cite: 28, 30]
* ระบบยกเลิกการจองให้อัตโนมัติเมื่อครบ 30 นาที[cite: 28]

---

## 🛠️ โครงสร้างไฟล์ (Project Structure)

* `connectdb.php` – เชื่อมต่อฐานข้อมูล MySQL[cite: 29]
* `api.php` – API จัดการระบบ (Login, Reserve, Check-in, Check-out, Release)[cite: 28]
* `index.html` – หน้าเว็บสำหรับใช้งานและแสดงผังจอดรถ[cite: 30]

---

## ⚙️ การใช้งานเบื้องต้น (Quick Start)

1. สร้างฐานข้อมูล `parking_db` ใน MySQL และรันคำสั่ง SQL สร้างตาราง `users` และ `parking_slots`[cite: 28, 29]
2. วางไฟล์ทั้งหมดไว้ในโฟลเดอร์ Web Server (เช่น XAMPP: `htdocs/`)
3. เปิดใช้งานผ่านเบราว์เซอร์ที่ `http://localhost/index.html`
