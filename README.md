# 🚗 Parking Management System (ระบบบริหารจัดการโรงรถ)

ระบบบริหารจัดการที่จอดรถใต้ตึกคณะ Computer Science สำหรับตรวจสอบสถานะช่องจอดรถและจัดการการเข้า-ออกของยานพาหนะแบบ Real-time

---

## 🛠️ Tech Stack & Technologies Used

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS), FontAwesome Icons
* **Backend:** PHP (RESTful API)
* **Database:** MySQL
* **Version Control:** Git & GitHub
